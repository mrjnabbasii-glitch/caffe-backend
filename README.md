# کافه آرامش

سامانهٔ رزرو میز کافه با رابط فارسی Vue 3، Quasar و Pinia و API مبتنی بر Express و MongoDB.

## پیش‌نیازها

- Node.js نسخهٔ ۲۲ یا جدیدتر
- npm
- MongoDB محلی یا Docker؛ اجرای محلی خودکار نیز در دسترس است.

## نصب و اجرای محلی در ویندوز

دستورها را در پوشهٔ اصلی پروژه اجرا کنید:

```powershell
npm.cmd run setup
npm.cmd run dev:local
```

در اولین اجرا ممکن است فایل اجرایی MongoDB دانلود شود. اطلاعات این حالت در `server/.local-db/` ذخیره می‌شود و وارد Git نمی‌شود. آدرس رابط کاربری را از خروجی Vite بردارید؛ معمولاً `http://localhost:5173` است.

## اجرا با MongoDB جداگانه

```powershell
docker compose up -d
Copy-Item server/.env.example server/.env
npm.cmd run dev
```

در صورت استفاده از MongoDB دیگر، مقدار `MONGODB_URI` را در `server/.env` تنظیم کنید. فایل واقعی `.env` نباید در مخزن قرار بگیرد.

## تست و ساخت

```powershell
npm.cmd test
npm.cmd run build
```

برای ارائهٔ خروجی ساخته‌شده توسط بک‌اند:

```powershell
$env:NODE_ENV = 'production'
npm.cmd start
```

در این حالت `NODE_ENV=development` را از فایل `server/.env` حذف کنید یا به `production` تغییر دهید. سرور روی `127.0.0.1:3000` گوش می‌دهد؛ انتشار عمومی به تنظیم reverse proxy روی میزبان نیاز دارد.

## ساختار

- `server/src/`: API و مدل‌های دیتابیس
- `server/test/`: تست‌های بک‌اند
- `cafe-aramesh-final-task/src/`: رابط کاربری
- `scripts/`: اجرای هم‌زمان سرویس‌ها و MongoDB محلی

## محدودیت‌های فعلی

- رزرو نهایی تاریخ پایان، آزادسازی خودکار یا مسیر لغو ندارد.
- پس از رفرش صفحه، ادامهٔ رزرو موقت در رابط کاربری بازیابی نمی‌شود؛ قفل سرور حداکثر پنج دقیقه باقی می‌ماند.
- شناسهٔ دسترسی رزروها در مرورگر ذخیره می‌شود؛ با پاک‌کردن داده‌های مرورگر یا تغییر دستگاه، دسترسی قبلی بازیابی نمی‌شود.
- وظیفهٔ قدیمی VS Code به فایل `START-WINDOWS.cmd` اشاره می‌کند که در این نسخه موجود نیست؛ از دستورهای بالا استفاده کنید.

این نسخه برای توسعه و نمایش اولیه مناسب است؛ پیش از بهره‌برداری واقعی، چرخهٔ پایان و لغو رزرو باید تکمیل شود.
