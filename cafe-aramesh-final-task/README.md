# فرانت‌اند کافه آرامش

این پوشه فرانت‌اند Vue پروژه است و از بک‌اند Node.js و MongoDB پوشه هم‌سطح `../server` استفاده می‌کند.

برای نصب، تنظیم MongoDB و اجرای یکپارچه، راهنمای `../README.md` را بخوانید.

اجرای فقط فرانت‌اند: `npm.cmd run dev`

بیلد: `npm.cmd run build`

در حالت توسعه، درخواست‌های `/api` به `http://127.0.0.1:3000` فرستاده می‌شوند؛ بک‌اند باید جداگانه در حال اجرا باشد.
